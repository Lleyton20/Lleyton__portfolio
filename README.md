# Lleyton Magama — Portfolio

A responsive, static portfolio for Lleyton Magama, a Computer Science student and software engineer. The page highlights verified education, experience, public projects, and contact details.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. The site uses plain HTML, CSS, and JavaScript; no package install or build step is required.

## Portfolio features

- Dark editorial visual system with responsive layout and accessible skip navigation.
- Animated hero positioning, scroll reveals, a flight-route story, project filters, and interactive skill tabs.
- Reduced-motion support and responsive touch-friendly interactions.
- Downloadable general software-engineering résumé: `assets/Lleyton_Magama_Resume.pdf`.
